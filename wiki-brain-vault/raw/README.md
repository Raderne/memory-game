# raw/

Immutable source documents to be ingested into `wiki/` pages (design exports, specs,
meeting notes, third-party docs).

**Files here are NEVER modified.** To use one, summarize it into a `wiki/` page, cross-link it,
update `wiki/index.md`, and add a line to `log.md`.

The main spec is currently the claude.ai/design project (see `wiki/Design Source.md`), and its
values are already transcribed into `plan/`, so nothing is stored here yet.
